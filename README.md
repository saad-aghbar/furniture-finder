# Furniture Finder

A floating, always-on-top search bar for Windows that searches all your Excel files —
in Hebrew, Arabic and English — and lets you copy the results in one click.

> 🚧 Under construction. This repository currently holds the full specification.
> Claude Code builds the app from `CLAUDE.md` and the `docs/` folder.

## Start the build
Open this folder in Claude Code and paste the prompt from `START_HERE.md`.
